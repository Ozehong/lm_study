# Git常用命令

```python
查看历史记录
git reflog
恢复操作
git reset <commit id>

新建分支
git branch <name>
切换分支
git switch <name>
推送本地分支到远程
git push -u origin deepseek

将已修改的文件添加到 Git 的暂存区
git add <name>
提交
git commit -m "Your commit message"
推送到远程分支
git push --set-upstream origin deepseek
拉取远程代码
git pull origin master
查看历史提交
git log

经典开了VPN无法git push解决方案：
1. 查询是否使用了代理: git config --global http.proxy
2. 取消代理： git config --global --unset http.proxy
3. git push

```

## Python导包问题最佳解决方案

1. 在项目根本路下创建path\_config.py

```python
import os
BASE_PATH = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
```

* 接下来每个类都添加这个代码

```python
import sys
import os
sys.path.append(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
from path_config import BASE_PATH
sys.path.append(BASE_PATH)
```
