# **DeepSeek-GRM：通用奖励建模的推理时扩展**

> 强化学习应用在大模型上的关键挑战在于，为**各种领域获取准确的奖励信号**，不仅仅**局限于可验证的问题或人为制定的规则**。本文研究通过增加推理计算量来改进针对通用问题的奖励建模，同时研究使用恰当的学习方法提高性能-计算量scaling的有效性。本文使用**point-wise生成式奖励建模（GRM）**，并提出了**自我原则批判微调（SPCT）学习方法**，由此得到了DeepSeek-GRM模型，并引入**元奖励（MetaRM）建模**来指导投票过程。实验结果在各种奖励建模基准测试中优于现有方法和模型，且不存在严重偏差
>

# **Introduction**

> ### **问题背景**
>
> 强化学习在 LLM 训练中广泛应用，奖励建模是关键部分，但在**通用领域获取高质量奖励信号困难**。现有**奖励建模方法在输入灵活性和推理时可扩展性方面存在局限**，学习方法也未充分研究推理时可扩展性及与奖励生成行为的关联。DeepSeek-R1等研究也表明，无论是在训练期间还是推理期间，只要有**高质量且稳定可靠的奖励机制**，LLM就能在特定领域中取得优异的表现
>
> * **高质量奖励获取的挑战：**&#x7279;定领域的高质量奖励主要来自于人类设计的、条件明确的环境，或者为可验证问题精心制定的规则（数学和code任务）。在一般领域中，**奖励标准更加多样和复杂，而且往往没有明确的参考标准或事实依据**
>
> * **通用奖励建模的挑战：**
>
> 1. **对不同输入类型具有灵活性**
>
> 2. **在各种领域中准确地生成奖励**
>
> 3. **随着推理计算量的增加，能生成更高质量的奖励信号（Inference-Time Scaling）**
>
> 4. **学习可扩展的行为模式，以实现更好的性能-计算量扩展效果（Performance-compute scaling）**

> ### **奖励生成范式**
>
> * **Scalar 标量式：**&#x5BF9;于给定的 Query + Response，给出一个**标量奖励值**
>
> * **Semi-Scalar 半标量式：**&#x5BF9;于给定的 Query + Response，**奖励模型会输出一段Critique（打分的原因），同时再生成标量奖励值（**&#x53C2;&#x8003;**&#x20;Generative Verifiers 论文**，先让GenRM-CoT生成rationale，然后再提取最后生成YES/NO token的概率做奖励值）
>
> * **Generative 生成式：**&#x751F;成一段Critique，然后从中提取奖励，可以结构化的写在Critique里面

> ### **评分范式**
>
> * **Pointwise 逐点式：**&#x7ED9;每个Response**单独给一个分数**
>
> * **Pairwise 成对式：**&#x7ED9;两个Response打一个**相对的分数，或者从中选出一个最好的**

![](images/image-1.png)

> ### **RM范式**
>
> 基于上述的生成和评分范式，**不同的组合有不同的推理时扩展性和输入灵活性**
>
> * 成对式奖励奖励建模**只考虑成对回复的相对偏好**，缺乏接受单个或多个回复作为输入的灵活性。所以**PairRM以及LLM-as-a-Judge的方法缺乏输入灵活性**
>
> * 标量式奖励建模**很难为同一个回复生成多样的奖励信号（其生成的奖励是固定的）**，这样不好通过**基于采样的推理阶段扩展方法**来获得更好的奖励（比如**采样多个进行Voting，寄希望于Critique的多样性**）
>
> 基于上述的原因，本文选择了**生成式奖励生成范式 + Pointwise 评分范式的组合，也就是Pointwise GRM&#x20;**
>
> > **这个其实也是大家经常用GPT等强模型去造数据的时候的做法，就是写一些细则Prompt，让模型输出一段Reasoning和一个Score，然后把Score提取出来，但本文更重要的是后面的SPCT和MetaRM的方法**

# **Method**

> ### **基于采样的Pointwise GRM**
>
> 为了在推理阶段扩展计算资源的使用，本文专注于基于采样的方法，针对相同的Query和Response生成多组奖励，然后对这些奖励进行聚合，所以**奖励建模的Inference-time scaling主要取决于是否可以从这多次采样中得到不同的奖励**。本文所用**逐点生成式奖励建模（Pointwise GRM）**&#x7684;公式如下：
>
> $$\left\{S_{i}\right\}_{i=1}^{n}=f_{point }\left(\mathcal{R},\left\{y_{i}\right\}_{i=1}^{n}\right)=f_{extract }(C), \mathcal{R}=C \sim r_{\theta}\left(x,\left\{y_{i}\right\}_{i=1}^{n}\right), S_{i} \in \mathbb{R}$$
>
> 其中$$x$$是 query 内容，$$y_i$$是 response，$$r_{\theta}$$是奖励函数，$$\mathcal{R}$$奖励，$$C$$是Critique，$$S_{i}$$是$$y_{i}$$的单个得分，$$f_{extract }(\cdot)$$从生成结果中提取奖励，本文设置分数是离散的且为十分制（1～10）
>
> ### **利用原则（Principles）来提升奖励质量**
>
> Generalist RM 需要去生成除了专业领域还有通用领域（奖励标准更加复杂和多样性）的高质量奖励。对于一般领域，本文**使用原则（Principles）来指导奖励生成，而不是基于规则（Rule-based）**。利用principles指导奖励生成的公式如下，其中$$p_i$$为原则：
>
> $$\mathcal{R} = C \sim r_{\theta}(x, \{y_i\}^n_{i=1},\{p_i\}^n_{i=1})$$
>
> 本文做了一个初步的实验，用模型自己生成的原则并进行过滤之后的生成效果对比，可以看到提升明显：

> ### **Self-Principled Critique Tuning (SPCT)**
>
> 具体的方法叫 **自原则批判微调 SPCT**，可以让 LLM **学习生成自适应且高质量的原则（Principles），从而有效地指导批判（Critique）内容的生成**，SPCT包括两个阶段：**冷启动 rejective fine-tuning 阶段，以及 rule- based online RL阶段**
>
> 在这之前，本文将原则融入生成层面，即将原则视为奖励生成的一部分，也就是GRM会自行生成原则并根据原则生成Critique内容然后提取奖励，形式化如下：
>
> $$\left\{p_{i}\right\}_{i=1}^{m} \sim p_{\theta}\left(x,\left\{y_{i}\right\}_{i=1}^{n}\right), \mathcal{R}=C \sim r_{\theta}\left(x,\left\{y_{i}\right\}_{i=1}^{n},\left\{p_{i}\right\}_{i=1}^{m}\right)$$
>
> 这样原则能够基于输入的 query 和 response来生成，从而**自适应地匹配奖励生成过程**。随着大规模生成的原则，**生成式奖励模型有可能在更合理的标准范围内输出粒度更细的奖励**，对于推理阶段的可扩展性来说也是至关重要的

### **Rejective Fine-Tuning as Cold Start**

这部分主要是用预训练&#x7684;**&#x20;GRM 对奖励建模数据中的 query 和其对应的 response（可能有多条） 采样N次（生成principles+Critiques，然后提取奖励），拒绝策略是拒绝预测奖励和真实值不一致的（比如真实值是responses1比response2好，但是生成的奖励确实response2值更大），以及所有N次都正确的query和response（过于简单）**，数学上描述为，其中$$r_i$$为query$$x$$的第$$i$$个response$$y_i$$的ground truth奖励，前提是真实奖励值中只有一个最大值：

$$\left\{\begin{array}{ll}
\forall i \neq j, S_{j}>S_{i}, j = \arg\max_{l}\{r_{l}\}_{l = 1}^{n}, & \text{if } n \geq 2, \\
S_{1}=r_{1}, & \text{if } n = 1.
\end{array}\right.$$

> **此外对于某些很难生成对奖励的query和response来说，本文把ground truth加到了prompt中进行hinted sampling，这种只采样一次。这种做法会简化生成的Critique内容（太短了），也表明了对其做online RL的潜在必要性和好处**

### **Rule-based Online RL**

在冷启动之后，GRM会进行 Online GRPO 训练，**使用原始的GRPO设置，但是去掉了format奖励，取而代之的是采用更大的KL惩罚系数**，来确保格式正确并避免出现严重偏差。Rule-based Reward具体设置如下：

对于给定的query$$x$$和response$$\{y_{i}\}_{i = 1}^{n}$$，输出$$o_{i}$$的奖励为： $$r_{i}= \begin{cases}1, & \text{if } n \geq 2 \text{ and } \forall j \neq i, S_{i}>S_{j}, j = \arg\max_{l}\{r_{l}\}_{l = 1}^{n} \\ 1, & \text{if } n = 1 \text{ and } S_{1}=r_{1}, \\ -1, & \text{otherwise} \end{cases}$$

其中，奖励$$\{S_{i}\}_{i = 1}^{n}$$是从$$o_{i}$$中提取出来的。这个奖励函数和前面做 RFT 的拒绝策略差不多，可以用来优化GRM生成的原则和批判内容来区分最佳回复



> ### **Inference-Time Scaling with SPCT**
>
> 本文进一步探索了基于采样的推理时扩展方法
>
> * **Voting with Generated Rewards：简单的投票法，即采样多个轨迹，然后将提取的奖励聚合（SUM）起来**
>
>   $$S^*_i = \sum^k_{j=1}S_{i,j}$$
>
>   > Voting过程实际上将奖励空间扩大了 *k&#x20;*&#x500D;，并使生成式奖励模型能够生成大量的原则，这有利于提高最终奖励的质量和粒度。一个直观的解释是，**每个原则都可以看作是判断视角的一种代表，那么更多的原则可能会更准确地反映真实的分布情况，从而实现可扩展的效果**
>
> * **Meta Reward Modeling Guided Voting：**&#x968F;机性以及模型局限性会导致多次采样的原则和批判内容偏差、质量参差不齐，所以本文又训练了一个 **MetaRM 来判断 GRM 生成的原则和批判内容的正确性，即输出Meta Reward值，选出Top K\_meta，然后再去做 Voting**
>
>   > MetaRM 通过在 RFT阶段的采样轨迹以及 GRM 自身采样轨迹上进行二元交叉熵训练

# **Experiments**

> ### **Performance on RM Benchmarks**
>
> 标量式奖励模型和半标量式奖励模型在不同的基准测试上呈现出有偏差的结果，在可验证任务（PPE Correctness）上的性能明显优于所有生成式奖励模型，但在其他不同的基准测试中分别表现不佳。**SPCT 提高了 GRM 在通用奖励生成方面的能力，与标量式和半标量式奖励模型相比，偏差明显更小**

![](images/image-5.png)

> ### **Inference-Time Scalability**
>
> 在最多进行 8 次采样的情况下，DeepSeek-GRM-27B 在 greedy decoding 的基础上，性能提升幅度最大。进一步提升到 32 次采样时，有很强的性能提升潜力。MetaRM 也证明了在筛选低质量轨迹方面的有效性

>
> SPCT 不同组成部分的消融实验结果如图右所示👉
>
> * **即使没有进行冷启动，经过通用指令微调的GRM在经历在线强化学习后，性能仍有显著提升**
>
> * **Non-Hinted Sampling 比有 Hinted Sampling更为重要，这可能是因为在 Hinted Sampling 的轨迹中出现了简化现象**

>
> * DeepSeek-GRM-27B 32次采样的直接 Voting 方式，能够取得 671B MoE model相当的性能，
>
> * MetaRM Voting 在8次采样时就能取得最佳效果，与扩大模型规模相比，**DeepSeek-GRM-27B 在推理阶段的可扩展性是有效的**
>
> * 本文还使用 300样本的测试集对 DeepSeek-R1 进行了测试，发现其性能甚至比236B MoE RFT model还要差，这表明**为推理任务扩展长思维链并不能显著提升通用奖励建模的性能**

# **Conclusion**

> 本文引入了 SPCT 增强通用奖励建模在推理时间方面的可扩展性。借助Rule-based Online RL，SPCT 能够自适应地生成原则和批判内容，显著提升了 GRM 在不同领域中的奖励质量和推理时间的可扩展性。未来的研究方向可能包括将 GRM 作为奖励系统的通用接口集成到Online RL流程中，探索与策略模型进行推理时间协同扩展，或者作为基础模型的可靠离线评估工具。
