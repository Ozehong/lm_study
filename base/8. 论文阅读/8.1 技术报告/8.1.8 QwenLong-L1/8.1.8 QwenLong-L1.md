# **QwenLong-L1：迈向基于强化学习的长上下文大型推理模型**

> 近年来，**大型推理模型（LRMs）**&#x901A;过**强化学习**展现出了强大的推理能力。这些提升主要体现在**短上下文推理任务中**。相比之下，将LRMs扩展至通过RL有效处理和推理长上下文输入仍是一个尚未解决的关键挑战。**QwenLong-L1&#x20;**&#x9996;先**将长上下文推理 RL 范式形式化**，并**识别出训练效率欠佳和优化过程不稳定等关键挑战**
>
> **具体训练 pipeline： warm-up SFT&#x20;**→ **课程引导的分阶段 RL**（使用**难度感知的回顾性采样**策略来**鼓励探索**）
>
> **实验结果：**&#x5728;七个长上下文问答 benchmark 上的实验表明，**QwenLong-L1-32B&#x20;**&#x4F18;&#x4E8E;**&#x20;OpenAI-o3-mini&#x20;**&#x548C; **Qwen3-235B-A22B&#x20;**&#x7B49;闭源LRMs，性能与 **Claude-3.7-Sonnet-Thinking&#x20;**&#x76F8;当
>
> **论文链接: https://arxiv.org/pdf/2505.17667**

# **Introduction**

> ### **整体介绍**
>
> **OpenAI-o1**、**DeepSeek-R1** 和 **Qwen-QwQ** 为代表的大型推理模型 LRM，通过强化学习探索和增强各类推理任务
>
> 经过**强化学习**训练后，LRM 展现&#x51FA;**&#x20;“慢思考”** 的现象，特征是其解决复杂问题时，输出的扩展的思维链中出现了**分治策略、回溯机制**等策略
>
> 这种过程提升了模型在 **短上下文任务（4K tokens）**&#x4E2D;的推理性能，但在需要 **强上下文grounding** 和 **多步推理的长上下文场景（120K tokens）**&#x4E2D;，可扩展性仍未得到探索。这一局限性**对需要与外部知识交互的实际应用**，例如 **Deep Research 深度研究**， 构成了重大障碍，因为在此类场景&#x4E2D;**&#x20;LRM 必须从知识密集型环境中收集并处理信息**
>
> 本文引入**长上下文推理强化学习的概念**：**从长上下文输入中检索并锚定相关信息，然后基于整合的信息生成推理链**
>
> 实验结果表明，**长上下文推理 RL 相比短上下文场景存在训练效率低下的问题，如图二所示：**
>
> * **奖励收敛延迟**，而这种差异源于处理长上下文输入时，**输出熵的显著降低，限制了策略的探索**
>
> * **优化过程不稳定**，表现为**KL散度的间歇性飙升**。不稳定性由输入长度分布的异质性导致的输出长度更长，从而引发的方差放大效应，进而在策略更新时产生更大的变异性

![](images/image-9.png)

> ### **QwenLong-L1 Overview**
>
> **渐进式上下文扩展策略**，主要包含三个组件：**warm-up SFT、课程引导强化学习适应从短到长的上下文、难度感知的回顾性采样策略**
>
> **同时，QwenLong-L1 框架集成了 基于规则和基于模型的混合奖励函数，平衡精确率和召回率**

# **Method**

> ### **长上下文推理RL**
>
> 本文对**带KL约束的强化学习目标**进行了扩展，**将上下文 context 融入公式**：
>
> $$\max_{\pi_{\theta}} \mathbb{E}_{x, c \sim \mathcal{D}, y \sim \pi_{\theta}(\cdot | x, c)}\left[r_{\phi}(x, c, y)\right] - \beta \mathbb{D}_{KL}\left[\pi_{\theta}(y | x, c) \| \pi_{\text{ref}}(y | x, c)\right]$$
>
> 其中，**输入$$x$$是一个短的问题，$$y$$是模型的输出，$$c$$则是上下文**。具体的上下文和问题的模版如下：

> ### **RL 算法**
>
> 这里简单介绍了一下 **PPO、GRPO 和 DAPO，可以复习一下[ 3.3 RLHF 基于人类反馈的强化学习](https://kcnd4kn8i6ap.feishu.cn/wiki/TQqTwh2uwiSrqYktIPccTQOcn0g)。**&#x5BF9;于长上下文输入而言，**注意力机制的二次复杂度使得价值网络的训练在计算上难以承受**，因此本文主要采用GRPO、DAPO的算法的**组归一化奖励**来估计**优势函数**，省略额外的价值网络

> ### **渐进式上下文扩展&#x20;**
>
> 为了解决前文提到的优化动态不稳定的问题，L1 的训练框架分为三层：
>
> * **Warm-Up SFT：**&#x4F7F;用从**教师模型蒸馏得到的高质量示教数据集**$$\mathcal{D}_{\text{SFT}}$$，数据集中的每条样本包含问题$$x$$，上下文$$c$$和**经过验证的标准推理路径回答$$y^*$$**。使用 SFT 初始化，得到一个稳健的策略，可以初步进行上下文理解、推理链生成和答案提取
>
>   $$  \mathcal{L}_{SFT}(\theta) = -\mathbb{E}_{(x, c, y^{*}) \sim \mathcal{D}_{SFT}} \frac{1}{|y^{*}|} \sum_{t=1}^{|y^{*}|} \log \pi_{\theta}(y_{t}^{*} | x, c, y_{<t}^{*})$$
>
> * **课程引导的分阶段强化学习：**&#x5F3A;化学习过程**分为 $$K$$ 个离散的阶段**，**每个阶段的目标上下文长度为 $$L_K$$。从初始输入长度 $$L_1$$开始，每一个阶段都逐步增加输入长度**，直到达到最大目标长度 $$L_K$$。即在第 $$k$$阶段，仅针对满足以下条件的样本进行训练： &#x20;
>
>   $$L_{k-1} < |x| + |c| \leq L_k, \quad L_0 = 0$$
>
> * **难度感知的回顾性采样：**&#x901A;过**对样本进行难度分数加权的重要性采样**，来选择性的回顾之前阶段的样本。具体的**难度分数为该样本的组奖励均值的倒数**：
>
>   $$diff(x, c)=\frac{1}{mean\left(\left\{r_{i}\right\}_{i=1}^{G}\right)}$$
>
>   更低的平均奖励对应更高的难度分数，回顾性采样时优先选择

> ### **混合奖励机制**
>
> 开放域问答等长上下文推理任务，答案本身具有多样性，过于严格的**基于规则的奖励可能会限制合理的答案变体**，进而损害整体性能。本文则将基于规则和基于大模型两部分奖励进行混合：
>
> * **基于规则的验证**：$$r_{rule}$$通过验证模型输出是否严格符合任务特定的正确性标准来确保精确性。对于问答任务，本文首先使用的正则表达式从模型生成的$$y$$中提取最终答案$$y_{ans}$$，然后将其与标准答案$$y_{gold}$$进行精确字符串匹配:
>
>   $$r_{rule}(y)=\mathbb{I}(y_{ans}=y_{gold})$$
>
>   本文省略了答案提取的格式奖励，**过度的格式奖励可能会简化学习目标，进而阻碍模型探索推理链的能力**
>
> * **LLM-as-a-Judge：**&#x4E3A;了弥补基于规则的精确字符串匹配带来的假阴性问题（false negative），**使用 LLM 来评估生成的答案和标准答案的语义等价性**，得到基于大模型的奖励值：
>
>   $$r_{LLM}(x, y) = \text{LLM}(x, y_{\text{ans}}, y_{\text{gold}})$$
>
>   评估的 prompt 模板如下表所示：
>
> 最后的奖励**取上述两个奖励的最大值&#x20;**$$r_{\phi}(x, y) = \max(r_{\text{rule}}(y), r_{\text{LLM}}(x, y))$$

# **Training**

> ### **训练数据集**
>
> * **RL 数据集：**&#x44;ocQA-RL-1.6K 总共 1.6K 的强化学习数据集，涵盖三个推理领域
>
>   * **数学推理：**&#x4F7F;用 DocMath 的600个问题
>
>   * **逻辑推理：**&#x4F7F;用 DeepSeek-R1 生成600个多选题，这些题目要求对法律、金融、保险和生产领域的真实文档进行逻辑分析
>
>   * **多跳（Multi-Hop）推理：**&#x4ECE; MultiHopRAG 和 Musique 中分别采样200个样本，总共400个，重点关注跨文档推理&#x20;
>
> * **SFT 数据集：**&#x4F7F;用 DeepSeek-R1 蒸馏得到 5300 个高质量的（问题，文档，答案）三元组。基于问题的质量、复杂度和多样性进行清洗与筛选，并对文档的质量和长度进行控制，以确保上下文信息的精确性

![](images/image-3.png)

> ### **训练细节**
>
> * **Base model：选择 R1-Distill-Qwen-14B** 和 **R1-Distill-Qwen-32B&#x20;**
>
> * **SFT训练：**&#x8F93;入长度 20K
>
> * **RL 训练：两阶段课程式上下文扩展**，第一阶段输入长度为 20K，第二阶段输入长度为 60K，并通过回顾性采样保留从第一阶段到第二阶段平均准确率为零的最难样本

# **Experiment**

> ### **主要实验结果**
>
> 在 long-context DocQA benchmarks 的主要实验结果如下表所示，同时有几点关键发现：
>
> * **SFT在长上下文推理中的效果有限：**&#x53;FT 模型仅在 14B 参数规模下平均提升 0.8 个点，在 32B 参数规模下提升 3.2 个点，且不同基准测试上的改进表现出显著差异
>
> * **强化学习带来的显著提升：**&#x31;4B 模型平均提升 4.0-4.1 个百分点，32B 模型平均提升 4.7-5.1 个百分点
>
> * **在主流大型推理模型中表现领先：**&#x51;WENLONG-L1-14B 平均得分 68.3，超越了 Gemini-2.0-Flash-Thinking、R1-Distill-Qwen-32B 和 Qwen3-32B，同时与 QwQ-32B 的性能相当。此外，QWENLONG-L1-32B 平均得分 70.7，超过了 QwQ-Plus、Qwen3-Plus、Qwen3-235B-A22B 和 OpenAI-o3-mini，甚至可与 Claude-3.7-Sonnet-Thinking 相媲美
>
> * **测试时缩放（Test-time scaling）可以带来额外提升：**&#x968F;着采样规模的增加，QWENLONG-L1-14B 的性能呈现持续提升

![](images/image-4.png)

> ### **消融实验结果**
>
> * **SFT消融：**&#x53;FT在所有实验设置中均带来显著的性能提升， SFT不仅加速了奖励提升，还在不同 RL 阶段维持了更低的梯度范数，能够优先实现性能增益而非格式对齐
>
> * **课程引导的分阶段强化学习消融：**&#x5206;阶段 RL 方法实现了显著的性能提升。单阶段 RL 表现出更高的不稳定性，表现为 KL 散度波动和熵崩塌
>
> * **难度感知回顾性采样消融：**&#x5F15;入难度感知回顾性采样策略，将前序训练阶段的部分困难样本整合到当前训练数据中。该策略与分阶段强化学习结合后进一步提升了性能。尽管经过第一阶段 RL 训练，这些保留的困难样本仍导致奖励显著降低且策略熵更高，这促使策略模型加强探索过程

![](images/image-5.png)

> ### **额外分析**
>
> * **优化过程中 SFT 与强化学习的权衡：**&#x5C3D;管需要更多训练数据，但 SFT 仍具备显著的实用优势，包括降低计算复杂度、减少基础设施需求以及降低对专业技术知识的依赖，从而使其成为一种经济高效的性能提升策略
>
>   * SFT 与 RL 具有不同但互补的目标。SFT 以较低成本实现可接受的性能，而 RL 对于取得最优结果不可或缺
>
>   * 要实现性能最大化，需将 RL 置于 SFT 之上，因为过度关注 SFT 可能导致模型陷入局部最优，进而限制 RL 带来的改进空间
>
> * **长上下文推理行为的涌现与动态变化：**
>
>   * **上下文锚定（grounding）**：模型在长上下文中召回相关信息以支持后续推理，例如“让我浏览提供的文本以找到……”
>
>   * **子目标设定**：模型将复杂问题分解为多个可处理的子目标，以逐步解决问题，例如“为了解决这个问题，我们首先需要……”
>
>   * **回溯**：模型识别生成内容中的错误并返回迭代修正推理路径，例如“这种方法行不通，因为……”
>
>   * **验证**：模型通过自我反思系统验证预测答案的正确性，例如“让我们通过……来验证这个结果”
>
>   1. 所有大型推理模型均表现出显著的推理行为，其中**长上下文锚定的发生频率最高**，凸显了其在推理过程中处理上下文依赖关系的有效性
>
>   2. RL 训练会逐步增强这些推理行为，且与性能的提升相关，这表明**RL在优化输出空间以优先考虑有助于获得正确解决方案的推理模式方面是有效的**
>
>   3. SFT 模型的推理行为有所增加，但未能转化为性能提升，这可能是**由于SFT本质上依赖模仿学习，该学习更注重表面模式对齐，而非实质性推理技能的学习**
