# Quiet-STaR：语言模型可以在输出前自学思考

> **Quite-STaR是对Self-Taught Reasoner(STaR)的推广**，通讯作者都是一个。**Quiet-STaR让LLM学习在每个token处都生成rationales或者thoughts以解释后续的文本，从而改进其预测的效果**。本文提出了一种**token并行采样算法，使用可学习的token来指示thought的开始和结束，**&#x751F;成的thoughts对难以预测的token有不成比例的帮助，并提高了语言模型直接回答难题的能力。在使用 Quiet-STaR LLM进行继续预训练后， GSM8K（5.9% 提升至 10.9%）和 CommonsenseQA（36.3% 提升至 47.2%）的零样本性能有所提高，并观察到自然文本中困难token的困惑度有所改善
>
> **论文链接:** **https://arxiv.org/pdf/2403.09629**

# 一、研究背景

> **研究背景：**
>
> * **文本中许多含义隐含于字里行间，理解这些隐含信息对LLM很重要。**&#x8003;虑以下场景:正在阅读一个复杂的数学证明，虽然最终的答案可能很清楚，但关键在于**理解初始条件和结论之间未说明的步骤**。在交谈中也一样，**我们依靠中间的假设和背景知识来理解所说的话，这种内隐的推理的能力是之前的像STaR这样的工作欠缺的**
>
> * 先前研究表明，推理有助于语言模型在各种任务中提升性能，但现有方法（比如STaR）通过从问答示例中推断rationale来学习推理的技术，但是**STaR仅限于特定的任务，并且需要访问预先存在的answer-rationale对，限制了推理的通用性和可扩展性**。而Quiet-STaR建立在STaR的基础上，**使LLM能够为他们生成的任何文本 生成rationale/thought，使推理过程更加通用和适用**

# 二、研究方法

> **问题陈述：**
>
> 本文在序列的**每对token之间引入一个辅助的rationale变量**，优化一个具有参数θ的语言模型，使其**有能力生成中间思考thought（或原理rationale）**，使得
>
> &#x20;                          **$$\theta^{*}=arg max _{\theta} E_{x}\left[log p_{\theta}\left(x_{i: n} | x_{0: i}\right., rationale \left._{\theta}\left(x_{0: i}\right)\right)\right]$$**
>
> 上面公式**根据0-i的token和其rationale/thought去预测next的i-n个token，而不是仅仅next token**
>
> 实现Quiet-STaR有几个挑战，**为每个token生成rationale在计算上是非常昂贵的，**&#x5E76;且**LLM本身就缺乏产生或利用这些内在思想的能力**。最后Quiet-STaR不仅需要预测下一个单词，还需要**考虑文本中更长期的依赖关系**
>
> **方法概述：**
>
> 主要分为**think、talk和learn**三部分，**think就是根据当前token以及这之前的token生成一个thought，由start开始end结束的token序列**，然后再condition这些thought token和原本的文本token去预测后续的一些token；**talk就是平衡next token prediction有无thought两部分的logits**，做一个平滑过渡，防止一开始OOD问题太过严重；**learn就是最后用基于策略梯度的强化学习算法REINFORCE去优化模型参数**，提高输出有用thought的概率

![](images/image-1.png)

> **Think 并行rationale生成：**
>
> Quiet-STAR 的一个关键挑战是**在输入序列中的每个token位置高效生成基本原理，这将需要对每个标记进行单独的前向传递，这对于长序列来说在计算上变得难以处理**，本文通过**特殊的mask处理来实现高效并行计算：**
>
> 具体来说，在当前位置的base text token处先生成thought token 1（condition当前的base text token及之前的token），当所有位置的thought token 1都生成了之后，**将thought token 1对应的对角线mask加在一开始的上三角mask之后，再去对每个位置都生成下一个thought token**。下左图只推了一步，我多画了一步（下右图）方便理解，红色框指示生成这个thought token需要condition的token对应的mask
>
> 本文在这一步**对于每个token都会生成多个thought，每个thought通过可学习<|startofthought|> 和<|endofthought|> token来标记开始和结束**

> **Talk 混合事后推理和基础预测：**
>
> 当从预训练模型开始训练的时候，**生成的thoughts一开始会out of distribution，从而损害性能**。为了平滑向思维的过渡，本文在有思维和无思维的 LM prediction之间引入了学习插值，具体实现是一个三层MLP混合头（Mixing Heads）
>
> **给定thought结束token的hidden state和对应的原始文本token的hidden state，混合头输出一个标量权重，这个权重用来加权 加不加thought 所产生的LM的prediction logits，这种方法可以在微调早期缓解分布变化问题（Distribution Shift）**

> **Learn 优化rationale生成：**
>
> * **优化 Start-of-Thought 和 End-of-Thought Tokens：**<|startofthought|> 和 <|endofthought|> token充当控制模型生成rationale/thought的meta-token。**优化这些token的表示，尤其是 <|startofthought|> 标记至关重要。**&#x672C;文将这**两个token embedding初始化为与长破折号“−−−”对应的embedding**，长破折号经常在文本中表示暂停或思考，这利用了先验存在的知识，后续在学习过程中会更新两个token的embedding参数
>
> * **Non-myopic Scoring and Teacher-forcing：**&#x975E;短视评分和教师加强指导。这部分看论文很难理解在说什么，简单来说就是**模型训练时thought对预测每个token的有用性不同，模型的奖励不应仅依赖于thought后的下一个token，而应更多地基于后续语义内容**，**所以我们利用当前token和thought往后预测多步同时用真实的token进行监督**。**教师强制技术就是下图里面的虚线，将一些已经有的token强制插入**，实线是LM自己生成，中间的标志是在做mixing head。这种方法**有助于模型在训练过程中更好地学习生成有用的思想，以提高对未来标记的预测能力**
>
> * **优化目标：**&#x4F7F;用**REINFORCE**来优化rationale的可能性，**在给定先前的token和特定rationale的情况下，模型的next $$n_{true}$$个token $$X_{j + 1:j + n_{true}+1}$$的对数似然(ahead tokens)**。**为了减少方差，每个token生成多个rationale**。定义每个rationale/thought $$T_j$$的奖励函数为混合当前thought和原始模型预测的对数似然与多个thought的对数似然平均的差：
>
>   &#x20;                   $$r_{j}=\log p_{j:j + n_{true}}^{talk}(X_{j + 1:j + n_{true}+1}) - \log \bar{p}_{j:j + n_{true}}^{talk}(X_{j + 1:j + n_{true}+1})$$
>
>   使用**REINFORCE损失项更新语言模型参数θ，以增加表现优于平均值的thought的似然性**：
>
>   &#x20;                $$\nabla_{\theta} \mathcal{L}_{j}^{REINFORCE} = -r_{j} \cdot \nabla_{\theta} \log p_{\theta}(T_{j}|[X_{:j};<| \text{start of thought}|>])$$

> **Quiet-STaR算法流程：**
>
> 算法流程还是很清晰的，值得注意的是本文最后在做**REINFORCE更新的时候将负奖励排除在强化学习损失项之外，这会使训练更稳定，尽管可能会引入一些偏差，同时还增加了一项NLLloss来维持LLM基础的next token prediction能力**

# 三、实验结果

> **所有的实验都是基于Mistral 7B base model**
>
> 1. **下游任务性能提升**
>
>    * 在 CommonsenseQA 和 GSM8K 数据集上，**Quiet-STaR 显著提高了模型的零样本推理能力，准确率分别提升了 10.9% 和 5.0%**，且随着推理标记数量增加，性能提升更为明显
>
>    * 在 C4 数据集上训练也能提升模型在上述数据集上的性能，但提升幅度较小
>
> 2. **改进分布**
>
>    * 平均而言，模型预测任意token的能力提升较小，但**对于较难的token，改进效果显著，这表明推理对挑战性标记更有帮助**
>
>    * 推理有助于预测需要回忆相关信息的标记，如定理名称或证明步骤的开始
>
> 3. **与思维链（Chain - of - Thought）的关系**
>
>    * 思维链提示和 Quiet - STaR 是正交且互补的，Quiet-STaR 允许模型在每个标记处进行推理，生成更结构化和连贯的思维链，在 GSM8K 测试中，多数投票准确率从 40.6% 提高到 47.7%

# 四、研究结论

> **局限性**
>
> 1. **训练条件的不确定性**
>
>    * 不清楚这些技术在模型从零开始训练时是否有效，因为研究仅应用于Mistral 7B base模型
>
> 2. **计算开销问题**
>
>    * Quiet - STaR 在生成每个额外token前会产生大量计算开销，生成许多中间token
>
> **结论**
>
> 1. **方法的意义与成果**
>
>    * Quiet - STaR使模型能从隐含的推理任务中学习，提高了下游推理任务的性能，且生成的rationale/thought具有一定意义
>
> 2. **未来研究方向**
>
>    * 可以尝试集成多个thought以进一步改进对未来token的预测，或者试图学习在何时进行思考，而不是每个token处都生成thought
