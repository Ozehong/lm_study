# PRM 过程监督奖励模型：让我们一步步验证

> 来自OpenAI的研究员探讨了在训练语言模型解决**复杂多步推理问题时，过程监督（process supervision）和结果监督（outcome supervision）**&#x4E24;种方法的效果，研究发现**过程监督在训练模型解决具有挑战性的 MATH 数据集中的问题时显著优于结果监督**
>
> **论文链接:** **https://arxiv.org/pdf/2305.20050**

![](images/image-4.png)

# 一、研究背景

> **研究背景：**
>
> * **大模型逐步推理过程中的逻辑错误和幻觉：**&#x5927;模型虽能通过逐步推理或者逐步思考（CoT, Chain of Thought）解决复杂任务，但即使最为先进的**模型也会产生逻辑错误和幻觉，需要通过监督奖励模型来区分理想和不理想的输出**
>
> * **奖励模型的过程监督和结果监督缺乏详细的对比研究：**&#x5956;励模型的训练方法主要有结果监督和过程监督。**过程监督具有提供更精确反馈、更易解释、更符合人类思维链等优点，但之前研究发现两者在小学数学领域最终性能相似**
>
> **研究目的：**&#x6BD4;较结果监督和过程监督在训练模型解决数学问题上的有效性，并**研究主动学习（Active Learning）对过程监督的影响**

# 二、研究方法

> **奖励模型建模：**&#x9A8C;证大模型结果的好坏，一般有两种不同的验证器结果奖励模型 ORM 和过程奖励模型 PRM，ORM 对整个解决方案进行评分，而 PRM 对推理过程中的每个步骤进行评分
>
> * **结果监督奖励模型（ORMs, Outcome-supervised Reward Models）：直接判断一个solution最终结果是正确还是错误的（有可能中间推理错误，最终结果正确的现象）**，从生成器（Generator）中均匀采样固定数量的解决方案solutions，训练 ORM 预测每个解决方案是否正确，**通过检查最终答案确定正确性**
>
>   **ORM的目标函数：**&#x7ED9;定一个数学问题$$p$$及其解$$s$$，ORM（$$P \times S \rightarrow \mathbb{R} $$）分配一个单实值给$$s$$以指示$$s$$是否正确，**ORM通常使用交叉熵损失进行训练**
>
>   &#x20;                                       $$  L_{\text{ORM}} = y_s \log r_s + (1 - y_s) \log (1 - r_s)  $$
>
>   其中$$y_s$$是标签（如果$$s$$正确则为1，否则为0），$$r_s$$是ORM分配的sigmoid分数或者说概率
>
> * **过程监督奖励模型（PRMs,Process-supervised Reward Models）：**&#x52A0;入了每一步step的标记，训&#x7EC3;**&#x20;PRM 预测每个步骤的正确性**，这样可以直接在自回归模型进行训练，同时在遇到结束位置标记时，训练PRMs去预测每一step是否正确。在测试时对整个solution进行一次 PRM 前向传递来确定step-level预测，将整个solution的 PRM 分数定义为每个步骤正确的概率累计乘积
>
>   **PRM的目标函数：**&#x66F4;进一步，PRM（$$  P \times S \rightarrow \mathbb{R}^{K + 1}  $$）为每个推理步骤分配一个分数，其通常使用以下公式进行训练
>
>   &#x20;                                  $$  L_{\text{PRM}}=\sum_{i = 1}^{K} y_{s_i} \log r_{s_i}+(1 - y_{s_i}) \log (1 - r_{s_i})  $$
>
>   其中$$y_{s_i}$$是解$$s$$的第$$i$$步标签，$$  r_{s_i}  $$是PRM分配给第$$i$$步的sigmoid分数或者说概率， 总共有$$K$$步推理
>
> **注：**&#x672C;文并没有显式的给出ORM和PRM的建模，上述建模公式来自论文 ***MATH-SHEPHERD: VERIFY AND REINFORCE LLMS  STEP-BY-STEP WITHOUT HUMAN ANNOTATIONS***，链接：https://arxiv.org/pdf/2312.08935
>
> * **ORM和PRM监督信号不对等的问题：**&#x5728;提供过程监督时，本文**有意选择只监督到第一个错误的步骤，这样做使得结果监督和过程监督之间的比较更加简单明了**。对于正确的解决方案，两种方法提供相同的信息，即每个步骤都是正确的；**对于不正确的解决方案，两种方法都揭示了至少存在一个错误，而过程监督还揭示了该错误的具体位置**。如果他们在第一个错误之后提供额外的过程监督，那么过程监督将具有更大的信息优势。这个决策还保持了对人类的标注成本相似：**在不依赖于易于检查的最终答案的情况下，确定解决方案的正确性等价于确定其第一个错误**

> **实验方法：**
>
> * **模型规模：**&#x5728;大规模和小规模两种情况下进行实验。大规模模型基于 GPT-4 微调，拿到最可靠的ORM和PRM，小规模模型设计类似但计算量少 200 倍，且都在MathMix数据集上进一步微调
>
> * **生成器Generator：**&#x8BAD;练生成器以换行分隔的逐步格式生成solution，对 MATH 训练问题进行少量生成并筛选出正确答案的方案，用其微调基础模型
>
> * **评估：**&#x5BF9;生成的结果进行N选1，最终根据答案来评分
>
> * **数据收集**
>
>   * **过程监督数据：**&#x7531;**人工标注**者对大规模生成器生成的 MATH 问题解决方案的每一步进行标注，分为**正、负、中性三类，收集的数据集称为 PRM800K**
>
>   * **选择策略：主动学习，**&#x4E3A;提高人工反馈价值，选择表面上看起来合理但答案错误的方案给标注者，并在数据收集过程中迭代重新训练PRM
>
>     * **基础方案：**&#x6BCF;一步推理都收集人类反馈结果
>
>     * **优化策略（高价值负样本挖掘）：**&#x6807;注数据的时候，尽可能对更有可能欺骗reward模型的数据来进行标注，如果展示明显错误的解决方案，获得的反馈价值没那么大
>
>     * **迭代训练奖励模型：**&#x5728;每次迭代中，对每个问题生成N个解决方案，并仅向数据标注者展示得分最高的K个具有说服力的错误答案解决方案。本文尝试将此top-K过滤应用于问题级别（每个问题K个解决方案）或全局级别（总共K个解决方案，在问题之间不均匀分布）

# 三、实验结果

> **大规模监督学习：**&#x6BD4;较PRM和ORM最佳表现与N的关系
>
> * 用 PRM800K 训练大规模 PRM，对 ORM 在训练集每个问题上进行 100 次均匀采样训练。结果显示 **PRM 在搜索大量模型生成的解决方案时比 ORM 和多数投票更有效**
>
> * 尝试用**RM-weighted voting 结合 PRM 和多数投票的优势，但未显著提高性能**
>
> 下图中N为每个问题采样solution的个数，随着N的增大，PRM和ORM的gap越来越大，说明**相对于ORM和Majority Voting，PRM能更有效的在众多答案中找到正确的答案**

![](images/image-1.png)

> **小规模合成监督学习：公平对比PRM和ORM**，由于数据集构建，监督方法的不同，以及结果评判方法的不同，直接对比ORM和PRM有点不太好比较
>
> * **问题原因：**
>
>   * **ORM和PRM的训练集无法直接进行比较，**&#x50;RM训练集是通过**主动学习**构建的，**偏向于错误答案的解决方案，并且规模小了一个数量级**
>
>   * ORM**最终答案的评分正确但可能推理过程错误带来评判不公平**
>
>   * 收集人工反馈的成本很高，无法轻易地通过人工标注者去除这些因素
>
> * **解决方法：**&#x4F7F;用大规模的PRM（PRMlarge）来监督较小的模型来进行相关的消融实验
>
> * **实验结果分析：**
>
>   * 直接比较结果和过程监督，发现**过程监督在所有数据收集规模上都显著优于两种形式的结果监督。**&#x540C;时图二中**使用PRMlarge进行结果监督明显比最终答案检查更有效，PRMlarge为结果正确，推理错误的解决方案提供了更好的监督**
>
>   * 研究主动学习的影响，发现**主动学习使过程监督的数据效率提高约 2.6 倍，但训练样本过多可能因缺乏多样性限制主动学习的效果**。同时对迭代重新训练选择器模型进行初步研究，虽未得到更好结果，但认为这是未来研究的一个有吸引力的方向

![](images/image-2.png)

> **OOD泛化：在未见过的 224 个 STEM 问题上评估大规模 ORM 和 PRM**
>
> * **方法：**&#x4E00;个包含224个STEM问题的保留集上评估了大规模ORM和PRM，这些问题来自最近的AP物理学、AP微积分、AP化学、AMC10和AMC12考试。这些测试是在预训练数据集编制之后发布的，因此可以高度确信模型没有见过这些问题
>
> * **结论：**&#x50;RM的泛化能力表现优于ORM和多数投票。这向我们表明，PRM可以容忍适度的分布变化，其强劲的表现在新的测试问题上保持不变

# 四、结论展望

> **过程监督的优势**
>
> * **信用分配更明确：**&#x8FC7;程监督提供更丰富的信号，**明确指出哪些步骤正确以及错误步骤的位置，使信用分配更容易，有助于模型更好地泛化**
>
> * **对 AI alignment的影响：过程监督更可能产生可解释的推理**，更安全直接地奖励符合人类思维的行为，**避免模型因学习利用奖励信号而产生偏差**，且不会导致性能下降，反而可能增加其采用率
>
> **本文贡献**
>
> * 证明过程监督比结果监督能训练出更可靠的奖励模型，**过程监督模型解决了 MATH 测试集代表性子集中 78% 的问题**
>
> * 表明**大型奖励模型可可靠地近似小型奖励模型的人类监督，并可用于大规模数据收集消融研究**
>
> * 显示**主动学习可显著提高过程监督的效率**
>
> * **发布 PRM800K 数据集以促进相关研究**
