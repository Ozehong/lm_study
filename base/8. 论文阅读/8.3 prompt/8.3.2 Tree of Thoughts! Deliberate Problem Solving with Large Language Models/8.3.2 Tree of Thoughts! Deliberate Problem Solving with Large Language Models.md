# 一、 研究背景

> 在我们处理新问题的时候，我们会经常意识到我们会需要反复的调整、探索才会得到最后的一个解决方案
>
> 探索过程中会生成一些启发式信息，有助于产生新的发现
>
> 因此就需要树结构

# **二、研究方法**

![](images/QOxEbqpaEoAC1BxrF0qcNaOanhh.png)

> ToT（Tree of Thoughts）顾名思义，就是**把线性的 CoT 换成了树结构**。用 GPT4 生成分支、判断哪条分支适合生长、迭代
>
> **关键步骤：**
>
> 1. 任务**拆解**（人工定义）
>
>    1. 粒度不能过细，这样会难以评估，比如生成一个 token
>
>    2. 粒度不能过粗，这样会难以生成正确结果，比如生成一本书
>
> 2. **生成**「思考步骤」“thought”：
>
>    1. 多次独立采样：适合生成空间较大的情况
>
>    2. 一次生成全部：适合生成空间较小的情况，能避免重复问题
>
> 3. **评估**「思考步骤」的可行性：
>
>    1. CoT 分级/打分
>
>    2. CoT 投票
>
>    3. 可以独立进行多次，进行 CoT-SC
>
> 4. 空间**搜索**：
>
>    1. BFS：每次广度搜索时，保留最优的 N 个点
>
>    2. DFS：每次深度搜索时，限制树的深度

![](images/image.png)

BFS：每次广度搜索时，保留最优的 N 个点

![](images/image-1.png)

DFS：每次深度搜索时，限制树的深度

| LLM 能力需求    | CoT  | CoT      | CoT、评估           |

# **五、研究总结**

> 这几个实验虽然都很简单，但其实能够反应现实世界中需要的能力，比如 Game of 24——科学探索、创意写作——写文章、迷你填字游戏——有约束情况下的最优化问题。
>
> **ToT 原理：**&#x4ED6;结合「自我评估」，考虑了每个「思考步骤」的可能性，从整个思维树中找出正确解。

# **六、业务应用**

> **难点：**
>
> * GPT4 博览群书，而人的经验有限，所以当人改写不熟悉的 query 时，很难超越 GPT4。而且人没有 GPT4 快。
>
> * 如果直接 ToT，GPT4 给自己答案的评价可能不准，影响效果。

> **方案：**&#x53;FT 改写中，GPT4 去做撰写、改写工作；人做选择、评价工作。
> 整个方法也可以做成闭环，反复优化 SFT 数据。

![](images/XzcmbPqXAoz8DqxfqeZcImN2nGc.jpg)

> **优点**：
>
> * 质量：回答全部是模型生成，人只是选择和评价，数据下限会比较高
>
> * 解耦：先选提纲，再选回答，解耦了行文逻辑和描述。
>
> * 效率：改写 → 选择 + 评价，应该能快一些

> **缺点**：
>
> * 自动化问题：平台不支持这种方式，所以流程上需要标注同学执行完一个阶段，我们抓取下一个阶段数据。标注同学也需要重新回忆 case。

> **生成的回答示例：**
>
> query = 交换机和路由器区别（moonshot-v1-32k，多级列表）
>
> 交换机和路由器的区别主要体现在以下几个方面：
>
> * **工作层次不同**：
>
>   * **交换机**：主要工作在OSI模型的\*\*数据链路层\*\*，即第二层\[1]\[6]\[9]。
>
>   * **路由器**：工作在OSI模型的\*\*网络层\*\*，即第三层\[1]\[6]\[9]。
>
> * **数据转发依据不同**：
>
>   * **交换机**：基于\*\*MAC地址\*\*进行数据帧的转发\[1]\[3]\[5]\[6]\[9]。
>
>   * **路由器**：基于\*\*IP地址\*\*进行数据包的路由选择\[1]\[3]\[5]\[6]\[9]。
>
> * **功能和应用场景不同**：
>
>   * **交换机**：主要用于\*\*局域网\*\*中，实现高速数据传输和交换，适用于文件共享、打印机共享等\[4]\[10]。
>
>   * **路由器**：用于连接不同网络，如\*\*局域网与互联网\*\*的互联，支持NAT转换，适用于互联网接入、VPN建立等\[8]\[10]。
>
> * **广播域和冲突域的处理**：
>
>   * **交换机**：可以分割\*\*冲突域\*\*，但不能分割\*\*广播域\*\*（传统交换机）\[6]\[9]。
>
>   * **路由器**：可以分割\*\*广播域\*\*，每个端口都是独立的广播域\[1]\[6]\[9]。
>
> * **附加功能**：
>
>   * **路由器**：具备防火墙服务、地址转换和包过滤等附加功能\[1]\[3]。
>
>   * **交换机**：通常不具备这些附加功能，但\*\*三层交换机\*\*有一定的路由功能\[8]。
>
> * **性能和成本**：
>
>   * **交换机**：性能较高，成本相对较低，适用于局域网内部的数据交换\[10]。
>
>   * **路由器**：功能更强大，但速度可能相对较慢，成本较高\[1]\[10]。
>
> * **端口和接口**：
>
>   * **交换机**：端口通常较多，端口颜色相同，接口上标注有规律的序列数字\[5]。
>
>   * **路由器**：端口较少，存在一个特别的\*\*WAN或Internet\*\*接口，颜色可能与其他接口不同\[5]。
>
> * **传输模式**：
>
>   * **交换机**：可以支持\*\*全双工\*\*和\*\*半双工\*\*操作\[6]。
>
>   * **路由器**：通常不涉及传输模式的讨论，主要关注路由选择和数据包转发\[6]。
>
> * **网络连接**：
>
>   * **交换机**：适用于\*\*局域网\*\*中的连接，通过MAC地址学习和转发\[9]。
>
>   * **路由器**：适用于\*\*广域网\*\*中的连接，通过IP地址路由\[9]。
>
> * **VLAN支持**：
>
>   * **交换机**：有些高级交换机支持\*\*VLAN\*\*功能，可以进行逻辑网络的划分\[7]\[10]。
>
>   * **路由器**：通常不涉及VLAN功能，但可以处理不同VLAN间的数据传输\[7]。
>
> query = 现在手机有必要贴膜吗（GPT4-0314，多角度归纳）
>
> 关于现在手机是否需要贴膜，不同人有不同观点：
>
> * 需要贴膜的理由：
>
>   * **防刮花**：贴膜可以保护手机屏幕免受划痕的影响\[1]\[4]\[6]。
>
>   * **保值**：贴膜有助于保持手机屏幕的完好，提高二手回收价格\[1]\[4]。
>
>   * **防摔**：贴膜在一定程度上可以缓解对屏幕的冲击，降低爆屏风险\[6]。
>
> * 不需要贴膜的理由：
>
>   * **手感**：裸屏使用手机手感更好，特别是对于高端旗舰手机\[1]\[5]。
>
>   * **屏幕硬度**：现在的手机屏幕硬度已经足够高，不易被刮伤\[2]\[5]\[9]。
>
>   * **消费观念**：手机是消费品，换代较快，无需过分保护\[10]。
>
> 总结：是否贴膜取决于个人需求和使用习惯。如果希望保护手机屏幕免受划痕和摔伤，可以选择贴膜；如果更注重手机的手感和原始观感，可以选择不贴膜。
