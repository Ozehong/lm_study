```python
def compute_loss(self, model, inputs, return_outputs=False):
            labels = inputs.pop("labels")
            # forward pass
            outputs = model(**inputs)
            logits = outputs.get("logits")
            # compute custom loss (suppose one has 3 labels with different weights)
            loss_fct = torch.nn.CrossEntropyLoss(weight=torch.tensor([neg_weight, pos_weight], device=labels.device, dtype=logits.dtype))
            loss = loss_fct(logits.view(-1, self.model.config.num_labels), labels.view(-1))
            return (loss, outputs) if return_outputs else loss
```

# **9.8.3 指标计算**

**用wandb监控指标**

> **注意，如果没有梯子连不上Huggingface的话，请执行以下代码。**
>
> `git clone `[`https://github.com/huggingface/evaluate.git`](https://github.com/huggingface/evaluate.git)
> `metric = evaluate.load("evaluate/metrics/accuracy/accuracy.py")`
>
>
>
> `evaluate.load("evaluate/metrics/accuracy/accuracy.py")`替换成`evaluate.load("accuracy")`

```python
def compute_metrics(eval_pred):
    precision_metric = evaluate.load("evaluate/metrics/precision")
    recall_metric = evaluate.load("evaluate/metrics/recall")
    f1_metric= evaluate.load("evaluate/metrics/f1")
    accuracy_metric = evaluate.load("evaluate/metrics/accuracy")

    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=-1)
    precision = precision_metric.compute(predictions=predictions, references=labels)["precision"]
    recall = recall_metric.compute(predictions=predictions, references=labels)["recall"]
    f1 = f1_metric.compute(predictions=predictions, references=labels)["f1"]
    accuracy = accuracy_metric.compute(predictions=predictions, references=labels)["accuracy"]
    return {"precision": precision, "recall": recall, "f1-score": f1, 'accuracy': accuracy}
```

# **9.8.4 实验结论**

1. 全量微调时，Bert效果最好，而且好很多

2. 随机抽样200条数据，LLM比Bert效果好

3. 长文本数据上，Bert效果依然比LLM好，LLM训练的epoch多点（2-3个左右）效果会有提升。

# **9.8.5 理论分析**

> 纯`Prompt`工程的方式，`LLM`还是比传统`BERT`方式的效果差不少。
>
> 个人认为这是`LLM`大模型的训练方式与BERT不同导致的。
>
> `LLM`以预测下一`token`为目标，是单向构建上下文（从左到右）；而`BERT`训练是以完形填空式任务为目标。相比于`LLM`，`Bert`能够在双向构建上下文理解，本身就适配NLU任务。
>
> 其次，由于微调的任务单一，可能导致LLM的出现灾难性遗忘导致通用能力大幅下降。
>
> 最后，从模型通用型角度来看，Bert在数据量充足时充分“过拟合”下游任务信息；而LLM的目的是通用性而不会去过拟合某个单一任务。
