## **自己构造DPO数据**

1. **方法一：拒绝采样**

> 让自己的模型针对 prompt 生成多个候选 response，然后用 reward\_model 筛选出来高质量的 response （也可以是 pair 对），拿来再次进行训练。

**几个需要注意的点：**

![](images/diagram.png)

* **拒绝采样代码实现**

  ```python
  import openai
  import random
  openai.api_key = 'xxx'

  # 生成候选响应的函数，使用不同的温度值进行采样
  def generate_responses(prompt, model="gpt-4", max_attempts=5, num_responses=3, max_tokens=100):
      responses = []
      temperatures = [0.3, 0.7, 1.0]  # 设置不同的温度值
      attempt_count = 0
      while len(responses) < num_responses and attempt_count < max_attempts:
          # 随机选择一个温度
          temperature = random.choice(temperatures)
          
          # 生成响应
          response = openai.Completion.create(
              model=model,
              prompt=prompt,
              max_tokens=max_tokens,
              temperature=temperature,
              n=1,
              do_sample=True  # 使用采样
          )
          
          candidate = response.choices[0].text.strip()
          
          # 通过拒绝采样技术，选择有效响应
          if is_valid(candidate):
              responses.append(candidate)
          
          attempt_count += 1

      return responses

  # 判断候选响应的有效性
  def is_valid(response):
      # 可根据实际需求增加复杂的有效性判断条件
      # 例如：长度限制、内容合理性、是否符合业务需求等
      if len(response.split()) < 10:  # 示例：响应至少10个词
          return False
      return True

  # 主程序
  if __name__ == "__main__":
      prompt = "请简要介绍人工智能的基础概念。"
      valid_responses = generate_responses(prompt)
      
      for idx, response in enumerate(valid_responses, 1):
          print(f"候选响应 {idx}: {response}")
  ```

最后利用训练好的`Reward Model`或者强基座模型打分，选出最佳的response作为`chosen`，剩余的随机抽一条作为`rejected`。

* **方法二：不同模型输出**

> 刚刚提到的拒绝采样可行的前提是，SFT模型能力够强大。**但是如果SFT模型能力较弱，通过自己采样出来的每条路径可能都比较差**，这样的偏好数据集没任何意义，只会误导模型向错误的方向进行优化。

* **几个需要注意的点：**

  1. **SFT模型尽量选择不同尺寸、不同厂的**，这样确保了回答风格的差异化，如果回答过于相似，小模型可能由于语义理解能力太差导致训练崩塌。

  2. 灵活使用API，可以直接用dpsk r1或者4o判断哪个风格的回答更好，并给出理由。

  3. **温度系数不要调太高**，一般就设置为0.1（推理任务除外）.

- **方法三：合成数据**

> 那你想自己弄一个偏好数据集咋办？答案是可以自己合成数据，大致思路是：建设一个技能库，即按照一级、二级、三级分类划分数据集，收集少量高质量种子数据，然后将其作为few shot，然后通过精心设计prompt及后续pipeline合成prompt并过滤低质prompt，随后利用4o或者SFT模型生成回答，并设计校对策略（人工、程序验证器、其他LLM等等）。

# 2. 评测方法

## 指标评测

* WeightedAverageAccuracy  加权平均准确率

* Perplexity 困惑度

* Rouge (Recall-Oriented Understudy for Gisting Evaluation)

* Bleu (Bilingual evaluation understudy)

* ELO Rating System

* PASS@K

## 模型评估（llm-as-a-judge）

* 中心化评测

  * 中心化评测模式下，裁判员模型只有一个，可靠性高，但容易收到裁判员模型的bias影响

* 去中心化评测

  * 去中心化评测方式，要求模型之间做peer-examination

  * 特点是公平性好，但计算量大，且鲁棒性不高
